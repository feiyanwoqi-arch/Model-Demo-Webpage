# 交互式光学模型图谱

一个面向大学基础光学教学的交互式网页模型库。项目按**概念域 → 学习路径 → 具体模型**组织，不把实验模型孤立堆放。

## 当前内容

### 反射

- R1 反射定律与表面粗糙度
- R2 平面镜虚像
- R3 球面镜成像
- R4 菲涅耳反射与布儒斯特角
- R5 全反射与倏逝场
- R6 光导纤维中的全反射

### 干涉

- I1 两列波的相干叠加
- I2 杨氏双缝干涉
- I3 多缝与衍射光栅
- I4 单层薄膜干涉
- I5 牛顿环
- I6 迈克耳孙干涉仪
- I7 法布里–珀罗多光束干涉

## 运行

项目是纯静态网页，无需安装依赖。

1. 克隆或下载仓库。
2. 直接用浏览器打开 `index.html`。
3. 也可以在仓库目录启动任意静态服务器。

例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 统一建模规范

每个模型都应形成以下闭环：

```text
直接操作 → 局部物理机制 → 状态量变化 → 数学关系 → 可观测结果 → 近似边界
```

视觉语义统一为：绿色表示入射或主动光路，青色表示反射或主结果，橙色表示透射、泄漏或第二通道，紫色表示相位、倏逝场或辅助波动量。

## 维护约定

- GitHub 是此项目后续维护的源代码主库。
- Google Drive 中的版本仅作为历史归档，不再作为主开发源。
- 新模型先归入概念域，再实现统一的模型接口与页面结构。
- 每次修改交互方向、角度定义或坐标映射时，都必须进行实际拖动验收。
- 物理公式、图形、数值与文字解释必须同步，不允许只改其中一层。

更多说明见 [`docs/RESEARCH_NOTES.md`](docs/RESEARCH_NOTES.md)。
