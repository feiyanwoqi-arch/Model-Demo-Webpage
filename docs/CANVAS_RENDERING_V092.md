# v0.9.2 Canvas 高清渲染修复

## 问题

模型页扩宽后，Canvas 的 CSS 显示尺寸增长，但内部位图仍保持原始 `1080×675`、`720×450` 等尺寸。浏览器只能把低分辨率位图插值放大，因此文字、坐标轴、曲线和光路整体发虚。

薄膜参数相图还存在第二个绘图原语错误：`rect(..., fill=null, stroke=...)` 仍执行填充，导致刚绘制的热图被浅色矩形覆盖，只剩边框和当前状态十字。

## 修复

新增 `assets/js/canvas-hidpi-v092.js`：

1. 保留模型原有逻辑坐标系；
2. 按 `CSS 尺寸 × devicePixelRatio` 创建真实 backing store；
3. 使用 Canvas transform 将逻辑坐标映射到高分辨率位图；
4. 浏览器缩放、窗口大小、左目录挂载和栏宽变化后自动触发统一重绘；
5. 拖动坐标继续返回模型逻辑坐标，避免高 DPI 后交互方向或灵敏度改变；
6. DPR 最低取 1，最高取 3，兼顾缩放清晰度和显存；
7. 修复 `fill=null` 的矩形与多边形仍覆盖底图的问题；
8. 使用高质量图像平滑处理热图等栅格数据。

## 适用范围

所有通过全局 `canvasAPI` 创建的反射、干涉和衍射 Canvas 均自动获得高清 backing store，不只针对薄膜旗舰。

## 自动测试

`tests/canvas-hidpi-v092.test.js` 检查：

- CSS 1620×1012.5、DPR=2 时，真实 backing store 为 3240×2025；
- 模型代码仍读取到逻辑尺寸 1080×675；
- transform 正确映射为 3×；
- 拖动中心点仍映射为逻辑中心；
- 描边矩形不再填充覆盖图表；
- 脚本加载顺序位于 core 之后、所有模型渲染器之前。
