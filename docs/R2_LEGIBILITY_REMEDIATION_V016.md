# R2 v0.16 可读性否决与整改报告

版本日期：2026-08-05

## 结论先行

R2 v0.15 的“验收通过”结论已撤销。用户在真实浏览器中指出：Canvas 字体过小、分析模块被压在右侧、下方文字显示不全。该反馈成立，说明此前验收仍未把“正常观看距离下可轻松阅读”作为最终事实。

v0.16 不在 v0.15 上做局部放大，而是重新分配页面空间，并新增对 Canvas 实际字号、全部文字绘制、字形安全边距和模块完整呈现的强制验收。

## 为什么上一轮没有发现

### 1. DOM 字号检查覆盖不到 Canvas

旧验收读取了标题、按钮、实时数值等 DOM 元素的 CSS 字号，却没有测量 Canvas 内部文字经过响应式缩放后的实际像素大小。因此逻辑字号看似存在，真实显示可能只有十几像素。

### 2. 把“存在”和“完整可见”混为一谈

旧测试允许主要模块可见比例达到 90% 即通过。这等价于允许底部 10% 被裁掉，正好掩盖了用户看到的下方文字不完整。

### 3. 同屏目标压倒可读性预算

为了让主实验台和两个分析模块处于一个视口，v0.15 把模块放在右侧窄列。这满足了“同时出现”，却牺牲了文字尺度和模块完整性。

### 4. 人工检查只看整体缩略图

上一轮虽然逐张查看截图，但检查方式仍偏向整体构图，没有以原始像素 100% 打开并逐字阅读 Canvas 标签。缩略图能发现大面积空白，却无法可靠判断一行教学文字是否轻松可读。

### 5. 只检查新绘制，没有监控全部绘制

第一轮 v0.16 截图中，旧代码仍在主图补画一行很小的“有限镜面”。新文字登记表没有记录这行旧文字，因此最初的角色字号检查没有捕获它。之后新增了 Canvas 全量文字拦截，记录每次清屏后的所有 `api.text()` 调用，旧代码意外补画的小字也会失败。

## 核心标准升级

完整规则见 `INTERACTIVE_MODEL_STANDARD_V13_LEGIBILITY.md`。关键新增项：

- 状态/结论有效字号不低于 18 px；
- 核心对象与路径标签不低于 16 px；
- 任何教学文字不低于 14 px；
- 每个文字包围盒必须完整位于 Canvas 内并保留安全边距；
- 当前检查模块必须 100% 可见，底部至少留 16 px；
- 同屏目标必须服从可读性，允许通过自然滚动查看完整模块；
- 截图必须以原始像素 100% 逐字阅读；
- 用户真实画面优先级高于实验室截图、自动指标和代码意图。

## v0.16 页面重构

### 布局

- 主实验台改为全宽，不再与分析区左右挤压；
- 分析区移动到主实验台下方；
- 1735 px 及更宽视口采用双列大模块；
- 1500 px 及以下改为单列模块，保证文字和图形尺度；
- 固定边缘按钮预留 80 px 安全沟槽，不覆盖模块标题或关闭按钮；
- 低高度桌面视口单独控制主 Canvas 高度，确保完整进入视口。

### Canvas 表达

- 减少冗余小字，保留物理链中的必要标签；
- 主图核心标签逻辑字号提高至 18–25 px；
- 分析模块标签逻辑字号提高至 16–21 px；
- 底部说明移入安全区域；
- “拖动镜面端点”移到镜面左侧，避免与右上判据卡重叠；
- 主图在旧装饰绘制完成后再次进行最终重绘，删除旧版小字；
- 取消 v0.15 的三个补丁式重复重绘脚本，避免新旧分析图叠画。

## 新验收体系

### 角色字号与完整模块审计

视口：

- 2560×1440
- 1920×1080
- 1735×865
- 1440×900
- 1366×768

检查：

- 主实验台宽度与分析区纵向顺序；
- DOM 标题、说明、实时量字号；
- 主 Canvas、机制模块、判据模块分别滚动到完整视图；
- 可见比例接近 1.000；
- 底部安全距离至少 16 px；
- Canvas 角色字号与文字边距；
- 首屏非空；
- 真实拖动物体；
- 参数抽屉完整可见。

最终结果：五种视口浏览器错误和严格断言均为 0。

### Canvas 全量文字审计

新增 `r2-canvas-text-audit-v016.js`，包装全局 `canvasAPI`：

- 每次 Canvas 清屏后重置文字记录；
- 捕获最终画面中实际执行的全部 `api.text()`；
- 自动计算显示字号与四边安全距离；
- 任何实际文字低于 14 px 即失败；
- 不依赖开发者是否主动把文字登记进新模块。

最终测量：

| 视口 | 主图最小实际字号 | 机制模块最小实际字号 | 判据模块最小实际字号 |
|---|---:|---:|---:|
| 1735×865 | 18.70 px | 17.86 px | 16.81 px |
| 1366×768 | 16.37 px | 27.95 px | 26.31 px |

两种用户关键视口下，全量文字错误和断言均为 0。

## 人工原尺寸复核

最终截图以原始像素逐张查看，逐一阅读：

- 主图顶部区域标题；
- 镜面端点、物体、眼睛、虚像和必要反射点标签；
- 判据卡三行文字；
- 物距/像距和两行底部说明；
- 机制图左右标题、物点、虚像点和底部结论；
- 判据图左右标题、必要点、所需区间、判据卡和底部结论；
- 左右边缘按钮与模块标题之间的空间。

最终未再发现：

- 旧版小号“有限镜面”；
- 模块被右侧窄列压缩；
- 模块底部文字被裁切；
- 边缘按钮覆盖模块标题或关闭按钮；
- 新旧绘图叠加；
- 低于标准的实际 Canvas 字号。

