# 反射基础模型工作台 v0.13

版本日期：2026-08-04

本轮将薄膜旗舰多轮迭代中形成的核心构建标准，首次批量应用到反射前三个模型：

- R1 反射定律与表面粗糙度；
- R2 平面镜虚像；
- R3 球面镜成像。

完整标准见 [`INTERACTIVE_MODEL_CONSTRUCTION_STANDARD_V1.md`](INTERACTIVE_MODEL_CONSTRUCTION_STANDARD_V1.md)。

## 1. 统一页面结构

三个模型不再使用“主图 + 永久右栏 + 向下排列全部解释图”的长页面，而统一为：

```text
紧凑研究问题与因果链

主实验台                    同步分析区
├── 直接拖动物理对象        ├── 分析模块 A
├── 四个核心实时量          └── 分析模块 B
└── 当前状态与判据

左侧边缘轨：分析模块选择
右侧边缘轨：统一参数与完整判据
```

### 同屏预算

每个反射基础模型最多同时挂载两个分析模块。原因不是功能不足，而是装置图和几何图需要保留足够线条、标签和角度空间。

默认挂载：

```text
局部机制 + 可观测量
```

可切换预设：

- 机制＋观测；
- 装置＋观测；
- 公式＋验证；
- 清空。

## 2. R1 反射定律与表面粗糙度

### 主操作对象

- 入射光源；
- 入射角；
- 局部法线分布；
- 观察方向。

光源和观察者都可以直接拖动。

### 物理升级

1. 将原“表面粗糙度”重新定性为“局部法线离散度（几何示意）”；
2. 明确它不是材料 RMS 粗糙度、BRDF 或波动散射求解；
3. 新增观察方向与角接受宽度；
4. 新增角分辨反射装置；
5. 新增微面元局部法线图；
6. 新增角分布和观察者相对接收信号；
7. 用矢量镜像式验证每条局部反射线。

### 统一因果链

```text
局部法线
→ 方向镜像
→ 法线方向分布
→ 反射角分布
→ 观察者/探测器是否接收
```

## 3. R2 平面镜虚像

### 主操作对象

- 物体顶端；
- 有限镜面；
- 眼睛/相机；
- 真实反射光；
- 反向延长线。

物体和眼睛都可以直接拖动。

### 关键物理修复

旧主图使用两个任意镜面命中点连接同一个理想点眼睛，这些路径不一定同时满足反射定律。

v0.13 改为：

1. 把眼睛表示为具有有限高度的两个瞳孔采样点；
2. 从虚像点连接到每个瞳孔点；
3. 求该直线与镜面的交点；
4. 由物点连接该交点，再连接瞳孔点；
5. 这样每条真实路径和反向追迹严格一致，并自动满足平面镜反射几何。

### 新增有限镜面判据

由物体顶部和底部的虚像点分别连接眼睛，计算两条视线在镜面上的交点：

```text
两个必要交点都落入有效镜面
→ 完整物体可见

任一交点超出镜面
→ 只看到部分物体
```

同时保留“眼睛可见”和“镜后屏幕不能接收会聚光”的区别。

## 4. R3 球面镜成像

### 主操作对象

- 物体；
- 凹/凸球面镜；
- 焦点和曲率中心；
- 主光线；
- 有效口径；
- 可移动屏幕。

### 物理升级

1. 主图保留近轴主光线和镜方程；
2. 新增有效口径控制；
3. 用真实球面法线逐条反射平行光束；
4. 计算各条光线与主轴交点的焦散宽度；
5. 新增光具座与屏幕相对像面偏移；
6. 新增 F、2F 成像区域相图；
7. 运行时提示近轴近似良好、有限或明显失效。

### 精确球面光束检查

对于每条入射平行光：

```text
求球面交点
→ 取该点球面法线
→ 使用矢量反射式
→ 求反射线与主轴交点
→ 统计所有交点的范围
```

该范围不是完整点扩散函数，但可直接显示球差如何随口径增长，并作为镜方程边界的动态判据。

## 5. 统一分析模块

每个模型均有五类模块：

1. 现实实验；
2. 局部机制；
3. 可观测量；
4. 从图到公式；
5. 自洽性与模型边界。

每个模块都注册：

```text
目的
作用
建议操作
```

公式模块使用 MathJax/LaTeX；验证模块随当前状态实时更新。

## 6. 统一自适应可见性

- 左侧模块选择器默认隐藏于窄轨；
- 右侧参数和完整判据默认隐藏于窄轨；
- 支持悬停延迟、点击、固定、关闭和 Escape；
- 手机/触屏采用底部显式按钮，不依赖 hover；
- 抽屉覆盖内容而不长期挤压主实验台；
- 用户选中的分析模块不会自动消失。

## 7. 自动验收

新增：

```text
tests/reflection-foundations-v013.test.js
tests/visual-audit-reflection-v013.mjs
```

浏览器验收针对：

- 1735×865；
- 1920×1080。

每个模型实际执行：

1. 打开模型；
2. 确认默认两个分析模块；
3. 将主工作区定位到当前视口；
4. 测量主实验台、局部机制、可观测量三者的可见比例；
5. 执行真实 Canvas 拖动；
6. 检查状态输出和可观测模块是否改变；
7. 打开左右抽屉；
8. 检查控件数量、抽屉宽度和横向溢出；
9. 截图并保存几何指标。

硬性标准：

- 三个关键卡片可见比例不低于 90%；
- 两个分析模块不得重叠；
- 分析画布宽度不低于 500px；
- 分析画布高度不低于 150px；
- 页面横向溢出不超过 2px；
- 直接拖动必须改变统一状态；
- 可观测模块必须随拖动重新绘制。
