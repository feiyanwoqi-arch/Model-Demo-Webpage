# v0.7 反射与干涉版块批判性审计与升级说明

## 1. 审计结论

旧版最主要的问题不是公式数量不足，而是**表示链断裂**：一个页面通常只有一张主 Canvas、若干滑块和普通字符公式。图中可能已经出现光线或条纹，但用户仍然不知道真实实验装置如何搭建、局部机制发生在哪里、图形和公式如何一一对应、最终仪器究竟测到什么。

物理教育研究反复强调：专家能力不仅是记住公式，还包括在装置、几何图、相量、曲线、符号方程与语言解释之间建立一致映射。多种表征如果只是并列摆放而缺少显式连接，也会增加认知负担。因此 v0.7 不采用“每个模型再加一段文字”的修补方式，而是重构模型页的信息架构。

## 2. 统一升级原则

每个反射和干涉模型现在按需要同时提供：

1. **主交互模型**：保留直接拖动和实时参数计算。
2. **真实实验装置图**：说明光源、器件、探测器和屏幕如何连接。
3. **局部机制放大图**：放大法线、边界场、相位突变、相量或路径差。
4. **观测结果图**：角分布、强度曲线、反射谱、条纹、屏幕像或扫描峰。
5. **因果链**：输入如何通过局部规律传递到可测量结果。
6. **LaTeX 推导链**：使用 MathJax 真实排版，并说明每一步来自哪张图。
7. **误区校正**：明确指出模型容易制造的错误直觉。
8. **模型边界**：区分几何光学、近轴、标量、无吸收、完全相干等近似。

## 3. 反射版块的主要整改

### R1 反射定律与表面粗糙度
- 增加转台式角分辨测量装置。
- 增加微表面局部法线放大图。
- 增加反射角分布曲线，展示粗糙度如何把窄峰展宽。
- 用矢量镜像公式替代只背 `theta_i=theta_r`。

### R2 平面镜虚像
- 增加“眼睛观察”和“镜后放屏”对照装置。
- 把真实光路与反向延长线严格分层。
- 增加位置、大小、正倒、可投屏性的性质判据。

### R3 球面镜成像
- 增加光具座、物体、镜面和可移动屏幕。
- 增加近轴光与边缘光比较，显式展示球差和镜方程的适用边界。
- 增加物距跨越 F、2F 时的成像区域相图。

### R4 Fresnel 反射与 Brewster 角
- 增加偏振片、样品转台和功率计装置。
- 增加 s/p 电场方向与入射面的局部图。
- 同步显示 Rs、Rp 曲线和当前角度，区分方向定律与能量反射率。

### R5 全反射与倏逝场
- 增加半圆玻璃块实验，消除入口面的额外折射干扰。
- 把“传播折射波消失”与“场完全为零”严格区分。
- 增加临界角前、临界状态和全反射区的连续状态图。

### R6 光导纤维
- 增加自由空间耦合透镜、光纤端面和输出屏。
- 明确区分外部入射角、纤芯轴向角和侧壁法线入射角。
- 增加 V 数模型选择图：何时可用射线直觉，何时必须使用波导模式。

## 4. 干涉版块的主要整改

### I1 两列波相干叠加
- 增加分束—移相—合束—探测装置。
- 增加首尾相接相量图。
- 增加强度随相位扫描曲线，展示相干度降低如何洗去交叉项。

### I2 杨氏双缝
- 增加激光、空间滤波、准直、双缝和屏幕的完整装置链。
- 增加同一屏点的路径差几何。
- 同时显示二维条纹和一维强度剖面。

### I3 N 个相干源
- 增加多缝—傅里叶透镜—焦平面装置。
- 增加 N 相量多边形。
- 增加不同 N 的峰宽比较，区分峰位和峰宽。

### I4 单层薄膜
- 增加宽带光源、准直、样品、收集透镜和光谱仪。
- 将传播相位与两个界面反射相位分开记账。
- 同时显示单色工作点和完整可见光反射谱。
- 明确两束近似与多重反射精确结果的层级。

### I5 牛顿环
- 增加 45° 分光片、共轴照明和显微镜观察装置。
- 增加空气膜横截面和 `t(r)` 几何。
- 增加 `r_m^2-m` 线性图，连接到真实测量方法。

### I6 Michelson 干涉仪
- 增加补偿片和完整两臂装置。
- 单独解释镜位移为什么让光程改变两倍。
- 增加镜位移—中心强度—条纹计数曲线。

### I7 Fabry–Pérot
- 增加可扫描平行腔、PZT 和探测器。
- 增加多次透射束相量几何级数。
- 同时显示 Airy 峰、自由光谱范围和精细度，区分峰距与峰宽。

## 5. LaTeX 渲染

v0.7 在入口页加载 MathJax 3.2.2。模型页的核心公式、推导步骤和公式列表均使用 TeX 源码渲染，不再使用 Unicode 字符模拟分式、上下标和希腊字母。

## 6. 交互和工程改进

- 新模型页仍使用旧模型的计算函数和主 Canvas，因此保持参数兼容。
- 三张补充图与主图共享同一状态对象，滑块或拖动后同步更新。
- 新增渲染令牌，离开模型页面后停止旧页面的动画循环，避免多个 `requestAnimationFrame` 持续运行。
- 衍射版块暂时保留 v0.6 页面，避免在本次修改中扩大回归风险。

## 7. 主要核验来源

- OpenStax, University Physics Volume 3：反射定律、全反射、平面镜、球面镜、偏振、双缝、多缝、薄膜和 Michelson 干涉仪。
- MIT OpenCourseWare：Waves in Medium、Interference / Soap Bubble、Modern Optics Laboratory。
- PhET 访谈研究：模拟器必须直觉可操作，否则学习者注意力会转移到界面操作本身。
- Physical Review Physics Education Research：多重表征和表征一致性是物理理解与实验理解的重要能力。

## 8. 尚未解决的问题

1. MathJax 由 CDN 加载，完全离线打开时不会排版；后续可考虑构建时本地打包。
2. 部分补充装置图为教学原理图，不是光机元件的工程尺寸图。
3. Fresnel 模型仍假设无吸收、各向同性介质；金属和复折射率尚未纳入。
4. 光纤模式图仍是分类提示，不是矢量本征模数值求解。
5. 薄膜白光颜色尚未加入真实光源谱、人眼色匹配函数和显示器色域的完整色度学链。
6. 所有模型仍需要持续进行逐项浏览器拖动和视觉回归验收。
