# R1 真实运行与视觉验收升级（v0.14）

## 本轮目标

本轮只处理 R1「反射定律与表面粗糙度」。不把单元测试、DOM 存在性检查或截图文件成功生成等同于页面验收通过。

验收必须建立在真实浏览器运行结果之上：

1. 启动静态网站并进入 `#model:reflection-law`；
2. 在目标视口实际执行拖动、滑块、预设、模块切换、抽屉打开与关闭；
3. 对首屏、关键状态和边界状态生成截图；
4. 人工查看截图中的真实呈现，检查布局、遮挡、裁切、可读性、层级、对齐和视觉反馈；
5. 发现问题后修改，再完整重跑；
6. 只有运行时断言和人工视觉检查同时通过，才可宣告完成。

## 核心验收标准调整

### 1. 真实呈现优先

代码结构正确、状态同步正确，只能证明实现基础存在，不能证明用户看到的页面合格。最终判据是浏览器中的实际视觉结果与交互结果。

### 2. 任务级验收而非元素级验收

验收脚本必须完成一段真实学习任务，而不是只检查某个元素可见：

- 拖动入射光源并读取入射角、反射角；
- 增加局部法线离散度并观察角分布展宽；
- 改变观察方向并判断接收信号；
- 切换分析模块并确认主实验台和两个模块仍可同时阅读；
- 打开参数抽屉后继续操作，确认抽屉不遮挡关键物理对象；
- 在多个视口中重复关键流程。

### 3. 视觉缺陷必须作为失败条件

以下任一情况均视为验收失败：

- 文本、数值、按钮或图形被裁切；
- 标签与光线、法线、边框或其他标签重叠；
- 关键对象缩小到不可辨认；
- 主实验台、实时量、判据和分析模块无法在同一任务上下文中读取；
- 控件打开后遮挡当前正在观察或拖动的对象；
- 信息层级混乱，用户无法判断先看哪里、再做什么；
- 同一状态在不同视图中视觉上不同步；
- 鼠标与触屏命中区域过小或反馈不清楚；
- 视口变化后出现空白浪费、拥挤、横向溢出或滚动陷阱。

### 4. 截图不是产物，而是证据

截图必须覆盖能暴露问题的状态，并由验收者逐张查看。截图生成成功本身不代表验收成功。

### 5. 完成声明必须附证据

完成说明至少包含：

- 运行过的测试与目标视口；
- 实际执行的交互任务；
- 发现并修复的问题；
- 最终截图清单；
- 仍存在的边界或未覆盖项。

## 最终执行记录

### 自动任务

每个目标视口均执行以下完整流程：

1. 加载 R1 默认态并把工作台滚动到可操作区域；
2. 检查主实验台、两个分析模块、Canvas 比例、字体、边缘按钮和横向溢出；
3. 真实拖动入射光源，将入射角从 38.0° 改到约 55.0°；
4. 打开参数抽屉并截图；
5. 将局部法线离散度设为 0.62；
6. 关闭参数抽屉，拖动观察方向至反射方向；
7. 确认相对接收信号达到 100.0%，并截图粗糙表面对准态；
8. 打开模块抽屉并截图；
9. 再次读取布局与溢出指标。

最终五个视口全部满足：

- 入射角：38.0° → 55.0°；
- 对准后的相对接收信号：100.0%；
- 页面宽度利用率：93.8%–95.3%；
- Canvas 显示比例：720∶260，未发生纵向拉伸；
- 控件、抽屉和边缘按钮：无裁切或文本溢出；
- 浏览器错误与验收断言：均为 0。

### 人工视觉检查

逐张检查了五个视口下的四类截图：

- `01-initial`：默认首屏；
- `02-parameters-open`：参数抽屉开启；
- `03-rough-aligned`：粗糙表面、观察方向对准；
- `04-modules-open`：模块抽屉开启。

检查重点包括：首屏信息层级、主实验台与分析区同时可读、光线和标签碰撞、抽屉遮挡、Canvas 比例、底部文字安全边距、边缘按钮命中与可读性、宽屏空白浪费和低高度视口拥挤。

### 真实验收发现并修复的问题

本轮不是一次通过，而是根据运行结果反复返工：

1. **旧测试全绿，但真实截图仍有问题**：边缘按钮文字截断、模块底部标签贴边、观察者只是小点、常驻实时量缺少接收信号；
2. **宽屏仍被 1540px 旧版容器锁死**：定位到 `#view:not(.mp-mounted)` 的通用规则，只对 R1 解除限制，避免影响主页和其他模型；
3. **分析 Canvas 被纵向拉伸**：强制保持 720∶260 设计比例；
4. **新验收脚本自身坐标写反**：入射光源纵坐标符号错误，修正后真实拖动稳定通过；
5. **机制图和角分布图底部说明被边界截断**：通过人工查看最终截图发现，将共享入射角与横轴定义移到顶部安全区域；
6. **主实验台物理链不完整**：新增局部法线、入射角与反射角、观察方向、接受角、角分布峰宽和相对接收信号的视觉关联。

## 最终结论

R1 v0.14 已完成“运行—操作—截图—查看—诊断—返工—完整重跑”的闭环。静态检查、物理回归、旧版反射任务测试和 R1 严格视觉审计均通过；最终截图经过实际视觉检查，未再发现影响当前五个桌面视口使用的明显裁切、重叠、比例失真或交互反馈问题。

当前未把移动端纵向窄屏纳入本轮完成范围；本轮合同明确面向上述五个桌面视口。项目级可复用标准已同步合并到 `INTERACTIVE_MODEL_CONSTRUCTION_STANDARD_V1.md` v1.1。
