# R3 v0.17 球面镜模型改进与验收记录

## 交付范围

R3 已直接更新到 `main`，不再使用独立开发分支作为交付面。此次交付只针对 `spherical-mirror` 球面镜模型，并保留 R1、R2 既有行为。

## 物理模型改进

1. 主图中的光线从有限高度真实物点出发，不再把有限物点误画成平行入射光。
2. 每条光线先与球面求交，再以交点到曲率中心的半径方向作为局部法线，使用向量反射公式求出精确反射方向。
3. 镜公式给出的近轴像面与有限口径光线追迹分开表达：前者给出理想近轴像距，后者显示球差和理论像面上的光斑高度。
4. 凹面镜焦外实像、焦内放大虚像和凸面镜缩小虚像统一采用同一套符号约定和成像判断。
5. 实际反射光使用实线；仅在虚像情形绘制反向虚延长线，避免把延长线误认为真实传播光线。

## 界面与交互改进

1. R3 页面脱离主页/分类页的 `1540px` 编辑阅读宽度限制；宽屏主工作区可使用原生视口宽度。
2. 主实验区位于上方，两个同步分析模块位于下方；宽屏双列、较窄桌面单列。
3. 直接拖动物体顶部时，物距和物高会在一次拖动中同步更新；自动验收目标为 `330 px / 145 px`。
4. 调整 `C=2F`、物体、近轴实像位置、镜面名称和状态卡位置，清除已知文字与图形碰撞。
5. 大口径状态会显示明显球差；参数抽屉保持完整可见并提供镜面类型、焦距、物距、物高、口径和屏幕位置控制。

## 最新验收规则

- 原生视口：`2560×1440`、`1920×1080`、`1735×865`、`1440×900`、`1366×768`。
- 每个视口保存主图、精确反射模块、成像区域模块、大口径状态和参数抽屉，共 25 张截图。
- 页面不得出现横向溢出；主工作区必须占视口可用宽度的至少 86%。
- 主图与两个分析模块在各自验收截图中必须完整可见，并保留至少 16px 底部安全距离。
- Canvas 普通文字有效字号不得低于 14px；核心物理标签不得低于 16px。
- Canvas 文字到四边必须满足安全距离；指定核心标签组合不得发生包围盒碰撞。
- 拖动后物距、物高、渲染版本和同步分析模块必须更新。
- 大口径球差、凸面镜虚像和参数抽屉完整性必须通过自动断言。
