# v0.9 模型页面结构标准与薄膜干涉学院士式审查

版本日期：2026-08-04

## 1. 本次问题的本质

薄膜旗舰 v0.8 已经具有装置、几何、相位、多束相量、光谱、相图、反演和验证等多种表征，但内容增多后出现了新的结构性问题：

1. 用户进入页面后能看到很多板块，却难以快速建立全局地图；
2. 用户不知道每个板块为什么存在、应该解决什么问题；
3. 多个板块虽然共享参数，但学习和推理顺序仍需用户自行猜测；
4. 页面标题主要使用视觉样式，语义化标题层级和区域标签不够完整；
5. 随着模型继续升级，若没有统一结构协议，所有模型都会重新陷入“内容越多越难用”。

因此 v0.9 的目标不是再增加一张物理图，而是建立一个可复用的信息架构：

```text
全页地图
→ 每节目的
→ 每节作用
→ 建议操作
→ 当前阅读位置
→ 模型边界
```

## 2. 研究依据

### 2.1 页内导航与语义结构

W3C WAI 的页面结构指南指出，页内导航和目录可帮助用户定位难以发现的长页面内容；标题应反映页面组织，导航区域应使用 `nav`，内容区域应具有可识别的标题和标签。

相关来源：

- https://www.w3.org/WAI/tutorials/page-structure/in-page-navigation/
- https://www.w3.org/WAI/tutorials/page-structure/headings/
- https://www.w3.org/WAI/tutorials/page-structure/sections/
- https://www.w3.org/WAI/tutorials/page-structure/labels/

### 2.2 直觉交互

PhET 基于两百余次学生访谈的界面研究指出：模拟器若不能直觉使用，注意力会从物理问题转移到软件操作本身。因此导航、拖动对象、反馈方向和页面层级必须自然对应。

相关来源：

- https://phet.colorado.edu/publications/archive/PhET%20Interview%20Paper%20Part%20II.htm

### 2.3 多重表征一致性

物理教育研究反复表明，专家能力不仅是拥有多种表示，还包括在装置、图形、数学、数据和语言之间灵活转换。仅把多张图并排放置并不自动产生理解；页面必须显式说明每种表示的目的和相互关系。

相关来源：

- https://journals.aps.org/prper/abstract/10.1103/PhysRevSTPER.4.010111
- https://journals.aps.org/prper/abstract/10.1103/PhysRevPhysEducRes.15.010142
- https://journals.aps.org/prper/abstract/10.1103/PhysRevPhysEducRes.20.020152

## 3. v0.9 已实现的通用结构

新增：

```text
assets/js/model-page-guide-v09.js
assets/css/model-page-guide-v09.css
```

这不是薄膜页面内部的临时代码，而是模型页面可注册的通用增强层。

### 3.1 左侧“本页项目栏”

桌面宽屏采用左侧吸附式目录，内容包括：

- 板块编号；
- 板块标题；
- 一句话功能摘要；
- 当前板块高亮；
- 阅读进度；
- 全模型统一边界；
- 返回所属知识域。

点击任一项目会平滑跳转到对应板块，并把键盘焦点移到该区域。页面滚动时，目录自动更新当前板块。

### 3.2 响应式行为

- 宽屏：左侧纵向吸附目录；
- 中等宽度：转换为页面顶部横向滚动目录；
- 小屏：压缩副标题，保留编号和主标题；
- 用户启用“减少动态效果”时，关闭平滑动画。

### 3.3 每节三项声明

每个主要板块顶部必须明确写出：

1. **本节目的**：这部分要回答什么物理问题；
2. **它的作用**：它在整条推理链中承担什么职责；
3. **建议操作**：用户怎样操作才能验证该部分，而不是被动观看。

### 3.4 标题语义

模型主标题使用 `h1`，主要板块转换为真实 `h2`，区域使用 `aria-labelledby` 关联标题。视觉结构和程序语义保持一致。

## 4. 所有模型页面必须遵守的“板块合同”

未来每个板块必须注册以下字段：

```text
id            唯一标识
number        页面顺序
label         板块标题
navigation    目录中的一句话摘要
purpose       本节要回答的问题
role          在整套模型中的功能
action        推荐用户操作
representation 当前使用的表示类型
input         读取哪些统一状态量
output        产生哪些图形或测量量
boundary      该板块的近似与失效条件
validation    能否被数值、守恒律或极限情况检查
```

页面不允许只因为“这张图很好看”而增加板块。每个板块必须拥有不可替代的功能；如果两个板块回答同一问题，应合并或明确区分尺度。

## 5. 所有模型的统一物理叙事顺序

并非每个模型都必须拥有相同数量的板块，但整体顺序应遵守：

```text
A. 定向：研究问题、对象、输出、边界
B. 控制：统一状态和直接操作
C. 装置：现实中如何产生与测量
D. 机制：局部物理规律在哪里发生
E. 传播：状态怎样从局部传到全局
F. 表征：几何、相量、场、公式怎样对应
G. 观测：仪器或人眼最终读到什么
H. 反演：能否由数据推回参数
I. 验证：守恒、极限、误差和适用边界
```

简单模型可以合并步骤，但不能跳过逻辑。例如反射定律不必拥有反演板块；薄膜光谱则应拥有。

## 6. 学院士式评价标准

对任何模型的评价不以动画数量为准，而按以下八项审查：

| 维度 | 核心问题 |
|---|---|
| 物理对象 | 基本对象、状态量和自由度是否明确？ |
| 局部规律 | 决定变化的边界条件或演化方程是否正确？ |
| 表征一致 | 装置、几何、相量、公式和曲线是否表达同一状态？ |
| 可观测量 | 页面显示的是物理状态还是实际探测器可测量量？ |
| 近似边界 | 近轴、标量、无吸收、完全相干等假设是否公开？ |
| 极限与守恒 | 是否通过退化极限、能量守恒、归一化等检查？ |
| 反演可信度 | 若由数据拟合参数，是否说明唯一性、误差和相关性？ |
| 工程可靠性 | 是否有语法测试、物理回归、视觉验收和性能控制？ |

任何一项严重失败，都不能以 UI 精美来补偿。

## 7. 单层薄膜旗舰的学院士式评价

### 7.1 已达到高水平的部分

1. **链条完整**：从真实装置、界面分束、传播相位、多束相量到反射光谱和参数反演已经闭合。
2. **精确多束内核**：在声明的无吸收单层平面膜边界内，对 s、p 偏振使用 Fresnel 系数和精确多束闭式解。
3. **近似层级公开**：两束近似与精确解同时显示，并给出误差。
4. **物理验证真实有效**：自动测试曾发现往返相位因子错误，修复后通过四分之一波增透、零厚度、等折射率、能量守恒等极限。
5. **正向与反向问题兼具**：不只调参数看结果，还能由带噪光谱反演膜厚。
6. **多表征联动**：公式对象、几何对象、相量和光谱共享同一状态。

### 7.2 当前不能称为“物理学意义上的百分百”的关键原因

#### P0-1：白光计算仍把折射率视为常数

当前 `n₁,n₂,n₃` 在 380–780 nm 内保持不变。真实材料一般具有色散 `n(λ)`，因此峰位、相位和综合色都会变化。白光旗舰模型若要进入研究级，应加入材料模型或用户可编辑的色散函数。

建议：

- 增加空气、水、熔融石英、BK7 等经过来源核验的材料预设；
- 使用 Sellmeier/Cauchy 模型计算 `n(λ)`；
- 参数栏同时允许“材料模式”和“常数 n 教学模式”。

#### P0-2：全反射和倏逝传播目前仍是保护性简化

当前遇到某些无实数折射角的情况会退出普通薄膜路径。更一般的三层膜应允许复数传播角和复数纵向波矢，从而描述倏逝层、受抑全反射和隧穿式耦合。

建议：

- 将传播常数统一写成复数 `k_z`；
- 使用支持复折射率和复角度的传输矩阵；
- 区分第一界面全反射、第二界面倏逝场和有限膜隧穿。

参考：Steven J. Byrnes, Multilayer optical calculations, arXiv:1603.02720。

#### P0-3：综合色仍是“标准色度的近似实现”

当前采用 CIE 1931 色匹配函数解析近似和约 6500 K 黑体光源。它已远好于直接把波长染色，但不等同于官方 D65 光谱和官方 1 nm CIE 数据。

建议：

- 将 CIE 官方 1931 2° 数据集和标准 D65 光谱纳入仓库；
- 明确色度适应、归一化、线性 RGB 与显示器 sRGB 编码；
- 显示“物理光谱”和“显示器近似颜色”之间的差异。

官方数据：

- https://cie.co.at/datatable/cie-1931-colour-matching-functions-2-degree-observer

#### P0-4：盲样拟合只在折射率已知时反演膜厚

当前反演是一个较理想的一维参数问题。真实光谱中膜厚、折射率、色散、粗糙度、角度偏差和仪器响应可能相关，单一最优值不等于唯一真值。

建议：

- 显示损失函数 `χ²(d)` 全局曲线，而非只给最优点；
- 报告置信区间、次优极小值和参数可辨识性；
- 加入双角度或同时测量 R/T 的模式，展示增加观测如何打破简并；
- 以后再加入 `d + n` 联合反演，而不是在当前页面直接堆入所有未知量。

薄膜光谱反演与多角度/多谱测量的相关研究：

- https://opg.optica.org/ao/abstract.cfm?uri=ao-48-5-985
- https://opg.optica.org/ao/abstract.cfm?uri=ao-45-19-4547
- https://opg.optica.org/ao/abstract.cfm?URI=ao-62-30-8018

### 7.3 P1 级升级

1. 显示膜内驻波场 `|E(z)|²`，把相量和空间能量密度连接起来；
2. 支持复折射率 `n+iκ`，显示吸收率和膜内吸收分布；
3. 将光谱仪分辨率、收集数值孔径和光源线宽实现为明确卷积，而不是笼统平均；
4. 加入椭偏参数 `Ψ,Δ`，说明强度谱与相位敏感测量的差别；
5. 加入拟合残差图和参数灵敏度 `∂R/∂d`。

### 7.4 应拆成独立模型的内容

以下内容不应继续塞入单层膜旗舰，而应建立新模型：

- 多层增透膜和高反膜设计；
- 金属膜、表面等离激元和复折射率；
- 楔形膜、肥皂膜厚度空间分布和二维彩色条纹；
- 各向异性膜与双折射；
- 超表面和亚波长结构；
- FDTD/FEM 全波数值求解器。

“旗舰”不等于无限大杂烩，而是在明确对象边界内形成完整闭环。

## 8. 对当前旗舰的综合结论

在“无吸收、平行、各向同性单层介质膜”的教学—虚拟实验边界内，v0.8/v0.9 已经达到高水平，强项是逻辑闭环、精确多束、跨表征联动和物理回归测试。

但从严格光学建模角度，材料色散、复角传播、官方色度数据和反演可辨识性仍是四个最高优先级缺口。因此准确评价应为：

```text
高质量旗舰教学实验：是
研究级通用薄膜求解器：否
已达到网页技术极限：否
可作为全项目页面与验证标准：是
```

## 9. 全项目迁移策略

### 第一阶段：结构迁移

所有反射、干涉和衍射模型接入：

- 本页项目栏；
- 真实 `h2` 标题；
- 本节目的、作用、操作；
- 当前板块高亮；
- 模型边界。

### 第二阶段：内容去重

逐模型检查：

- 是否有两个板块表达同一件事；
- 是否缺少装置或最终观测；
- 是否有公式无法映射到图中对象；
- 是否有图形无法回答明确问题。

### 第三阶段：物理分级

每个模型标记：

```text
示意模型
解析理想模型
数值精确模型
现实实验近似
反演模型
```

不得让低层级模型用高层级措辞包装。

### 第四阶段：验收

每个迁移模型至少通过：

- JavaScript 语法检查；
- 一个极限情况；
- 一个守恒或归一化检查；
- 一次实际拖动方向验收；
- 一次宽屏和窄屏视觉验收；
- 导航和标题语义检查。

## 10. 后续维护规则

1. 新增板块前先写 `purpose / role / action`，写不出来则不得新增；
2. 新增公式必须能指向物理对象或测量量；
3. 新增现实参数必须说明它通过什么数学操作进入结果；
4. 新增近似必须同时增加边界说明和至少一个验证；
5. 页面导航配置与板块标题必须来自同一注册数据，避免两套名称漂移；
6. 薄膜页面是第一份完整注册，其他模型逐个迁移；
7. GitHub 是唯一主代码源，文档与代码必须同一次升级提交。
