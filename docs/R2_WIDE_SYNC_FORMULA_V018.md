# R2 v0.18：宽屏同步对照与公式优先验收

## 用户否决

R2 v0.16 虽提高了 Canvas 文字可读性，但将主实验台与同步分析区机械改为上下排列，并且只放大公式卡片，没有放大 MathJax 公式本身。该版本在用户真实浏览器中不通过。

## 修正原则

1. 宽屏必须优先支持同步左右对照；
2. 上下排列只能是中等或窄屏降级方案；
3. 同步分析区必须获得真实可读宽度，不得再次压成窄栏；
4. 公式是教学主体，必须直接测量 MathJax 最终实际字号；
5. 容器变大但公式仍小，视为验收失败；
6. 用户实际视口 1790×896 纳入硬性专项验收。

## 桌面布局合同

- 视口宽度 ≥1600px 且高度 ≥760px：主实验台与同步分析区左右并列；
- 主实验台宽度不低于 850px；
- 同步分析区宽度不低于 600px；
- 两列顶部差不超过 24px；
- 同步分析区位于主实验台右侧，而不是下方；
- 视口宽度 <1600px：保留 v0.16 的纵向可读布局。

## 公式合同

- `从图到公式` 模块至少捕获三条可见 MathJax 公式；
- 每条公式最终计算字号不低于 22px；
- 每条公式必须完整位于模块边界内，四边安全距离不低于 8px；
- 推导行高度不低于 62px；
- 公式字号以 `getComputedStyle(mjx-container).fontSize` 为最终事实，不使用 CSS 声明值代替。

## 验收视口

- 1920×1080
- 1790×896（用户真实画面专项）
- 1735×865

## 发布闭环

本地 PR 验收通过后合并 `main`。公网工作流必须轮询 GitHub Pages，确认 v0.18 CSS 已发布，再在 1790×896 下重新检查左右布局、公式字号、公式安全边界和真实拖动。只有公网证据写入 `docs/live-evidence/r2-v018/` 后才可宣告上线完成。
