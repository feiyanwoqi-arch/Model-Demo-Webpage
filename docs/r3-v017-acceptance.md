# R3 球面镜模型聚焦返工记录（v0.18）

## 返工原因

此前的 v0.17 验收主要验证了元素边界、字号和截图生成是否完成，但没有充分检查截图中的整体构图、信息层级和实际教学体验，因此即使自动断言通过，页面仍存在明显问题。本记录取代旧的 v0.17“已完成”结论。

## 本轮聚焦的具体问题

1. 默认物高和有效口径过大，模型打开后直接显示严重球差，不适合作为近轴成像的起点。
2. 主图光线数量和延伸范围过大，像点、物体、焦点和状态信息互相争夺注意力。
3. 原“精确反射”分析模块只是主图的压缩重复，没有解释单个入射点的局部法线与反射机制。
4. 成像区域模块使用近似线性定位，物距较大时当前位置容易堆在边界附近。
5. 1920 宽屏下主实验区与两个分析模块不能稳定地在第一视口内完整比较；分析模块文字也偏小。
6. 左右边缘控制器使用竖排文字，参数抽屉打开后容易遮挡主实验区。
7. 1366 和 1440 视口中的关键标签与底部说明字号不足。
8. 页面仍显示旧版本号 `R3 · v1.0`，与实际返工版本不一致。

## 已实施修复

- 默认教学状态改为物高 `60 px`、有效口径 `18%`，默认理论像面光斑宽度约 `7.86 px`，先展示近轴近似，再由用户主动增大口径观察像差。
- 主图只保留三条强调光线和两条淡色有限口径采样线；反射光在像点附近结束，不再横贯整个画布。
- 状态卡移至左上独立区域；实像/虚像标签使用白底小卡片，减少与光线交叉。
- 底部说明拆为两行，并提高小视口中的有效字号。
- “精确球面反射与球差”模块改为两个互补视图：
  - 单个入射点的入射光、局部法线和反射光；
  - 理论像面上的有限口径光斑离散。
- “成像区域相图”改用非线性的 `u/f` 映射，分别表达 `u<f`、`f<u<2f`、`u>2f`。
- 1920 及以上宽屏采用主实验区与双分析模块同屏布局；较窄桌面采用纵向排列。
- 边缘控制器改为横向胶囊按钮；参数抽屉缩窄，并在普通桌面宽度下为主实验区预留空间。
- 页面版本标识更新为 `R3 · v0.18`。
- 直接拖动继续同时更新物距和物高，自动测试目标为 `330 px / 145 px`。
