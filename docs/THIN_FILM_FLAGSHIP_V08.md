# I4 单层薄膜干涉旗舰虚拟实验 v0.8

## 1. 定位

v0.8 不是继续在旧模型旁边堆放解释文字，而是建立第一个“满规格物理模型页”，用于定义后续高质量模型的工程标准。

本模型闭合以下链条：

```text
真实实验装置
→ 三层介质几何与直接操作
→ 两个界面的 Fresnel 分束
→ 膜内传播相位
→ 多次反射复振幅级数
→ 反射/透射光谱
→ 光源谱与人眼颜色
→ 带噪声测量与参数反演
→ 物理自洽性检查
```

## 2. 已实现能力

### 2.1 真实实验装置

页面显示光源、准直透镜、偏振片、薄膜样品、角分辨收集光学、反射光谱仪和透射功率计。装置图与主模型共享同一参数。

### 2.2 直接操作

- 拖动入射方向把手改变入射角。
- 拖动薄膜下界面改变物理膜厚。
- 公式项与图形对象双向高亮。
- 所有图、数值和判据同步更新。

### 2.3 精确电磁边界模型

对 s、p 偏振分别计算 Fresnel 振幅系数，并使用单层膜精确复反射振幅：

```math
r=\frac{r_{12}+r_{23}e^{2i\beta}}
       {1+r_{12}r_{23}e^{2i\beta}},
\qquad
\beta=\frac{2\pi n_2d\cos\theta_2}{\lambda}.
```

反射率和透射率分别为：

```math
R=|r|^2,
\qquad
T=\frac{n_3\cos\theta_3}{n_1\cos\theta_1}|t|^2.
```

无吸收理想模型会检查：

```math
R+T=1.
```

### 2.4 两束近似与多束精确解

页面同时计算：

- 第一束直接反射光；
- 第二束膜内往返后的反射光；
- 后续十余束的复振幅部分和；
- 无穷几何级数的精确闭式解；
- 两束近似与精确反射率之间的误差。

因此模型不会把“画两束光”误当成“物理上只有两束光”。

### 2.5 界面相位记账

上下界面的反射系数分别显示正负号。负反射振幅表示相位翻转 π；传播相位与反射相位分开记账，避免使用脱离折射率顺序和偏振条件的机械口诀。

### 2.6 时间控制

公共光学相位支持：

- 播放/暂停；
- 0.25×、1×、4×；
- 前进或后退 1/16 周期；
- 时间滑条。

相量图中所有光束共同转动，但相对相位由薄膜参数决定。

### 2.7 理想理论 / 现实实验模式

理想模式使用唯一的膜厚和入射角。

现实模式增加：

- 膜厚高斯分布；
- 入射角高斯分布；
- 标量粗糙度造成的相干项衰减近似。

这些平均会降低光谱起伏和颜色饱和度。当前现实模式是教学近似，不等价于随机粗糙界面的完整 Maxwell 求解。

### 2.8 光谱与颜色

支持：

- 6500 K 黑体近似白光；
- 有限线宽单色光；
- 钠双线近似；
- s、p 与非偏振光；
- 380–780 nm 反射、透射和两束近似曲线；
- CIE 1931 2° 色匹配函数的解析近似；
- XYZ 到 sRGB 的转换。

显示颜色是“光源谱 × 薄膜反射谱 × 观察者函数”的结果，而不是给单个波长随意指定颜色。

### 2.9 二维参数相图

计算当前波长下的：

```text
膜厚 d × 入射角 θ₁ → 反射率 R
```

相图用于展示等相位结构和当前状态所在位置。

### 2.10 盲样光谱实验

可以：

1. 随机生成未知膜厚；
2. 生成带可重复随机噪声的反射光谱；
3. 对候选膜厚进行全谱最小二乘扫描；
4. 得到拟合膜厚与 RMSE；
5. 揭示真实膜厚并比较误差；
6. 导出 CSV。

这将模型从“看现象”推进到“由测量反演物理参数”。

## 4. “满规格”的范围

本页的“满规格”指：在**无吸收、各向同性、非磁性、平行均匀单层介质膜**这一明确模型边界内，完成从实验装置、交互、物理机制、解析计算、现实平均、观测、反演到验证的闭环。

它不声称已经覆盖：

- 复折射率与金属吸收；
- 多层膜；
- 各向异性和双折射；
- 磁光效应；
- 非平行楔形膜的完整二维场；
- 随机粗糙面的矢量散射；
- 纳米结构超表面；
- 全波 FDTD/FEM 求解。

这些属于其他模型或更一般数值求解器，而不是当前单层介质膜模型的遗漏。
