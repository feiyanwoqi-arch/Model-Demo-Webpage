# R4 v0.19：菲涅耳反射与布儒斯特角严格运行工作台

## 1. 升级目标

R4 不再把“反射方向图”和“反射率曲线”并排陈列，而是建立同一界面的完整因果链：

```text
入射方向
→ s / p 偏振分解
→ 电磁边界条件
→ 有符号反射振幅 r_s、r_p
→ 相位翻转与能量反射率 R_s、R_p
→ 混合偏振的探测信号
```

布儒斯特角由 `r_p` 连续穿过零点产生，而不是额外附加的一条经验公式。

## 2. 不可隐藏的物理本体

主实验台同时显示：

- 两侧折射率和局部法线；
- 入射、反射、透射方向；
- 光线宽度编码的混合偏振能量份额；
- s/p 偏振组成与反射后偏振纯化；
- 反射振幅符号、反射率、透射率和布儒斯特角；
- 高折射率到低折射率时的临界角边界及向 R5 的明确交接。

绿色入射源可直接拖动。菲涅耳角谱中的绿色当前角度线也可直接拖动，两种操作写入同一状态源。

## 3. 同步分析视图

工作台始终保留主实验台和两个同步分析槽位。槽位可在以下表示之间切换：

1. 菲涅耳角谱；
2. 振幅、相位与能量账本；
3. 边界条件剖面；
4. 偏振分辨反射计。

默认组合为“菲涅耳角谱 + 能量账本”，保证方向、曲线和守恒关系在同一视觉瞬间可比较。

## 4. 物理内核

独立文件 `assets/js/r4-fresnel-physics-v019.js` 提供：

- 斯涅尔折射解；
- s/p 有符号反射振幅；
- `R=|r|²`；
- 无吸收单界面的 `R+T=1`；
- 布儒斯特角；
- 临界角和全反射边界；
- 任意 p 偏振能量占比下的混合反射率。

反射 `r_p` 采用固定实验室方向符号约定，使正入射时 s、p 使用同一相位判据；功率反射率不依赖此符号选择。

## 6. 模型边界

本模型假定均匀、各向同性、无吸收、非磁性介质。金属、吸收介质和多层膜需要复折射率与复振幅。全反射后的倏逝场、Goos–Hänchen 位移与 s/p 相位差属于 R5 的主体范围。
