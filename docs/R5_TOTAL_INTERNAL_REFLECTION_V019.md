# R5 v0.19：全反射与倏逝场同步工作台

## 1. 本轮目标

R5 不再把“折射光在临界角后消失”当作教学终点，而是建立一条连续、可操控、可验证的因果链：

```text
切向波数守恒
→ 临界角
→ 法向波数平方跨过 0
→ 传播折射波转化为倏逝解
→ 场幅随法向深度指数衰减
→ 局部探针与受抑全反射装置读出
```

主实验台、同步分析模块、参数抽屉、公式推导、模型边界和装置模块均读取同一状态源。

## 2. 统一状态与核心物理

工作台状态包括：

- 高折射率侧 `n₁`；
- 低折射率侧 `n₂`；
- 入射角 `θᵢ`；
- 真空波长 `λ`；
- `s`、`p` 或非偏振状态；
- 场探针深度 `z`；
- 第二介质间隙 `g`；
- 第二耦合介质折射率 `n₃`。

核心判据为：

```text
n₁ > n₂
sin θc = n₂ / n₁
kx = k0 n₁ sin θᵢ
kz² = (k0 n₂)² - kx²
```

当 `θᵢ < θc` 时，`kz² > 0`，低折射率侧存在传播折射波。

当 `θᵢ > θc` 时，`kz² < 0`，令 `kz = iκ`，场幅按下式衰减：

```text
E(z) ∝ exp(-κz)
δE = 1 / κ
δI = 1 / (2κ)
```

工作台同时计算 Fresnel 能量反射率与透射率、全反射下的 `s/p` 相位、相对相位差、局部探针场幅和教学尺度的间隙耦合量级。

## 3. 交互与可见反馈

### 主实验台

- 拖动绿色入射把手直接改变 `θᵢ`；
- 拖动紫色探针直接改变法向深度 `z`；
- 在未到临界角、临界附近、全反射和不存在临界角四类状态间连续切换；
- 同步显示临界角、反射率、透射率、穿透深度和探针场幅；
- 图例随物理状态变化：传播状态显示橙色传播折射波，全反射状态显示紫色倏逝场。

### 同步分析模块

- 传播解到倏逝解的波数转变；
- 倏逝场空间衰减与局部探针；
- 受抑全反射装置；
- 公式推导；
- 数值验证与模型边界。

同屏预算固定为两个互补模块，避免以压缩字号换取模块数量。

## 6. 模型边界

当前 R5 面向均匀、平面、无损、各向同性、非磁性介质。主图中的倏逝波列是用于揭示空间衰减和界面相位传播的标量场表示。

受抑全反射模块中的：

```text
耦合量级 ∝ exp(-2κg)
```

是教学尺度的指数近似，用于显示间隙增大时耦合快速下降，不等同于完整三层介质的精确矢量传输矩阵结果。精确 TE/TM 场分量、Goos–Hänchen 位移、吸收介质和多层耦合需要进一步的矢量与多层模型。
